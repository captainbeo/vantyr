The 30-second version
  1. Create an account — you must accept the Privacy Policy to register. It is enforced, not decorative.
  2. Verify on Telegram from your profile to unlock the free trial (7 days of credits, window-limited).
  3. Create an API key in Keys ↗.
  4. Point any agent at https://miarouter.online with that key. That is the whole integration.

Why a gateway

Every provider has its own auth, its own error shapes, its own billing quirks. MiaRouter normalizes them: your client speaks one of the supported wire formats (OpenAI, Anthropic, Gemini) to one base URL, and the platform takes care of routing, billing, retries, and logs. When a provider has a bad day, you see one consistent error surface instead of five inconsistent ones.

All current models are billed per request: each API call costs the flat price listed on the pricing page, no matter how many tokens it moves. No per-token arithmetic, no surprise bills at 2 AM.
