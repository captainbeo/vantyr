// 00Quickstart — four steps to your first request

  1. Create an account at vantyr.xyz. Registration is free and takes a minute; email verification is not required to start.
  2. Top up your wallet from the Wallet page — pay with crypto (USDT/USDC over 8 networks; minimum $1). Credit lands in your account automatically once the transaction confirms.
  3. Create an API key from the Keys page. The full key is shown once — copy it then. You can set a quota ceiling, expiry, and restrict which models the key may call.
  4. Point your client at Vantyr — base URL https://vantyr.xyz/v1 with your key as the API token. Sections below show the exact config for Codex CLI, Claude Code, and generic OpenAI-compatible clients.
Everything on the Pricing page is generated from live configuration: what you see there is exactly what you are billed — no hidden fees, no per-key surcharges. Wallet balance is consumed per request as tokens flow; nothing is charged for failed requests.

// 01Pricing — how you are billed

Vantyr bills per token, in US dollars, per million tokens (1M). Input and output tokens are priced separately: the input rate applies to your prompt and context; the output rate (typically several times higher) applies to the model's reply. Cached/repeated prompt segments are billed at the discounted cache rate shown on the pricing page. When a request fails upstream, the held amount is refunded automatically — you are never charged for a response you didn't get.

Worked example

A typical coding session on claude-sonnet-5 that sends 30k input tokens and receives 5k output tokens costs: 30,000 × $0.26/1M + 5,000 × $1.30/1M = about $0.014. A month of heavy daily use lands in single-digit dollars.

Wallet mechanics

  • Wallet balance is in US dollars. Requests pre-authorize a small hold, then settle to actual token usage; the difference is returned immediately.
  • Set per-key quota limits on the Keys page to cap spend per key — useful for automation or shared team keys.
  • When the balance hits zero, requests stop before reaching the model — no surprise overdraft.

// 02Codex CLI setup

Codex CLI talks to Vantyr through the OpenAI Responses wire API. Two environment items: your key, and a provider entry pointing Codex at Vantyr.

1. Put your key in an environment variable

PowerShell (persistent)
[Environment]::SetEnvironmentVariable('VANTYR_API_KEY', 'sk-your-vantyr-key', 'User')
macOS / Linux (persistent)
echo 'export VANTYR_API_KEY="sk-your-vantyr-key"' >> ~/.zshrc   # or ~/.bashrc
source ~/.zshrc

2. Add the Vantyr provider to your Codex config

Edit %USERPROFILE%\.codex\config.toml (Windows) or ~/.codex/config.toml (macOS/Linux) and add:

# Use Vantyr as the model provider
model_provider = "vantyr"
model = "claude-fable-5"
review_model = "claude-fable-5"
model_reasoning_effort = "high"
disable_response_storage = true

[model_providers.vantyr]
name = "OpenAI"
base_url = "https://vantyr.xyz/v1"
wire_api = "responses"
env_key = "VANTYR_API_KEY"
supports_websockets = false
supports_standalone_web_search = false
request_max_retries = 1
stream_max_retries = 1
Keep the display name = "OpenAI" exactly as shown — Codex's compaction feature keys off that value. The provider ID (vantyr) is what you select; the name is a Codex internal signal.

Pick any model from the pricing table as your model. For long coding sessions, claude-sonnet-5 is the value choice; claude-fable-5 for the hardest problems.

3. Run it

codex "explain the build error in src/main.rs"

If you previously logged in to Codex with a ChatGPT account, that session is unaffected — the provider entry routes only Vantyr traffic; OpenAI traffic still uses your OpenAI auth. Never paste your key into auth.json or commit it to a repository.

// 03Claude Code setup

Claude Code routes through standard Anthropic environment variables:

macOS / Linux
export ANTHROPIC_BASE_URL="https://vantyr.xyz"
export ANTHROPIC_AUTH_TOKEN="sk-your-vantyr-key"
Windows PowerShell
[Environment]::SetEnvironmentVariable('ANTHROPIC_BASE_URL','https://vantyr.xyz','User')
[Environment]::SetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN','sk-your-vantyr-key','User')

Then start Claude Code normally. Set the model with claude /model claude-sonnet-5 or claude --model claude-fable-5.

Prefer the ANTHROPIC_AUTH_TOKEN form (bearer token) as shown above — it maps directly to how Vantyr authenticates requests.

// 04Any OpenAI-compatible client

Point the client at the Vantyr base URL and use your key as the API key:

Base URL
https://vantyr.xyz/v1
Python (openai SDK)
from openai import OpenAI
client = OpenAI(
    base_url="https://vantyr.xyz/v1",
    api_key="sk-your-vantyr-key",
)
resp = client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "hello vantyr"}],
)
print(resp.choices[0].message.content)
curl
curl https://vantyr.xyz/v1/chat/completions \
  -H "Authorization: Bearer sk-your-vantyr-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-sonnet-5","messages":[{"role":"user","content":"hello"}]}'

Supported endpoints: /v1/chat/completions, /v1/responses, /v1/messages (Anthropic), and /v1/models. For Anthropic-native clients, use base URL https://vantyr.xyz with the x-api-key header instead.

// 05Payments — crypto top-up

  • Top-ups are in USDT/USDC, priced 1:1 against the dollar, over 8 networks: TRON (TRC20), Solana, Ethereum, BNB Chain, Polygon, Plasma, TON, and Aptos.
  • Minimum top-up is $1. There is no maximum.
  • After you click Top Up, you get a payment address and amount — send exactly that amount from your wallet. Credit is applied automatically when the network confirms (usually 1–3 minutes; TON can take a little longer).
  • If your payment is stuck (sent but not credited after 30 minutes), note the transaction hash and contact support — the payment gateway records every order and it can be reconciled manually.
  • Wallet credit never expires. Top-up amounts are final once confirmed; see the Terms for the refund policy on unused balance.

// 06FAQ

Where do I see my usage and spend?

The Usage page in the console shows every request: model, input/output tokens, and the amount billed. The Wallet page shows balance and top-up history.

My key was rejected — what's wrong?

Check the key is the full sk-… value (Keys page shows it masked; recreate if you lost it), that it hasn't expired or hit its quota ceiling, and that your wallet balance isn't zero. The error response always states which of these it is.

Which model should I pick?

claude-sonnet-5 for most coding and chat (best quality per dollar); claude-fable-5 when the task is genuinely hard; gpt-5-6-luna or gpt-6-sol when volume matters more than peak quality.

Do you support function calling / tool use / streaming?

Yes — all standard client features (streaming, tools, structured outputs) pass through unchanged on every model.

Is my data used for training?

Vantyr is a relay: your prompts and completions are forwarded to the upstream model provider and logged only as billing metadata (token counts, model, timestamp) — never message content.
