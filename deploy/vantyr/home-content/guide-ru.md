# Vantyr API

Премиум-доступ к Claude и Codex по цене в разы ниже официальных тарифов — один ключ, одна панель управления, оплата по факту использования или безлимит.

## Начните за 5 минут

1. **Создайте аккаунт** — [зарегистрируйтесь](/register), затем [войдите](/login). После этого привяжите свой **Telegram** в разделе Безопасность → Привязки аккаунта, чтобы получить **$5 бесплатного баланса** — этого хватит, чтобы как следует опробовать все модели, карта не нужна.
2. **Пополните баланс** — откройте страницу [Кошелёк](/wallet), выберите сумму пополнения и оплатите картой (Stripe).
   К каждому запросу применяются тарифы PAYG (оплата по факту использования); подробности — на странице [Модели и цены](/pricing).
3. **Создайте API-ключ** — перейдите в раздел [Ключи](/keys), нажмите **Создать**, задайте имя и скопируйте ключ.
   > **Совет:** оставьте включённой опцию **Неограниченная квота**. Поле квоты ограничивает суммарный расход этого ключа; в режиме без ограничений расход контролирует баланс вашего кошелька.
4. **Настройте свой инструмент на Vantyr** — базовый URL `https://vantyr.xyz/v1` (заглушка; см. домен запуска), заголовок авторизации `Authorization: Bearer sk-...`.

## Использование Codex CLI

Добавьте это в `~/.codex/config.toml` (создайте файл, если его ещё нет):

```toml
model = "gpt-6-astra"
model_provider = "vantyr"

[model_providers.vantyr]
name = "Vantyr"
base_url = "https://vantyr.xyz/v1"
wire_api = "responses"
env_key = "VANTYR_API_KEY"
```

Затем экспортируйте ключ и запустите:

```bash
export VANTYR_API_KEY="sk-..."
codex
```

**Рекомендуемые модели:** `gpt-6-astra` (флагман), `gpt-5-6-luna` (бюджетный вариант). Модели Claude работают в любом инструменте, совместимом с OpenAI.

## Использование любого клиента, совместимого с OpenAI

```bash
curl https://vantyr.xyz/v1/chat/completions \
  -H "Authorization: Bearer sk-..." \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-5", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Пользователям Claude Code и SDK Anthropic: укажите в `ANTHROPIC_BASE_URL` значение `https://vantyr.xyz`, а в `ANTHROPIC_API_KEY` — ваш ключ Vantyr.

## Вопросы

- **Ошибка «insufficient quota»?** Ваш кошелёк пуст — пополните баланс на странице [Кошелёк](/wallet).
- **Ошибка «429 rate limit»?** Вы достигли лимита запросов в минуту. Подождите минуту или свяжитесь с нами, чтобы повысить лимит.
- История использования: страница [Журналы](/logs) показывает каждый запрос, его токены и стоимость.
