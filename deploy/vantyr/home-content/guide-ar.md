# Vantyr API

وصول مميّز إلى Claude وCodex بجزء صغير من الأسعار الرسمية — مفتاح واحد، لوحة تحكم واحدة، بالدفع حسب الاستخدام أو بشكل غير محدود.

## ابدأ خلال 5 دقائق

1. **أنشئ حسابًا** — [سجّل](/register)، ثم [سجّل الدخول](/login). بعد ذلك اربط حساب **Telegram** لديك من الأمان → ارتباطات الحساب لتحصل على **رصيد مجاني بقيمة 5 دولارات** — ما يكفي لتجربة كل الطُّرز كما يجب، دون الحاجة إلى بطاقة.
2. **أضف رصيدًا** — افتح صفحة [المحفظة](/wallet)، واختر مبلغ الشحن، وادفع بالبطاقة (Stripe).
   تسري أسعار الدفع حسب الاستخدام (PAYG) على كل طلب؛ راجع صفحة [الطُّرز والتسعير](/pricing).
3. **أنشئ مفتاح API** — انتقل إلى [المفاتيح](/keys)، وانقر **إنشاء**، وامنحه اسمًا، ثم انسخ المفتاح.
   > **نصيحة:** أبقِ خيار **الحصة غير المحدودة** محدّدًا. يحدّ حقل الحصة إجمالي إنفاق هذا المفتاح؛ أما الحصة غير المحدودة فتترك التحكم في الإنفاق لرصيد محفظتك.
4. **وجّه أداتك إلى Vantyr** — عنوان URL الأساسي `https://vantyr.xyz/v1` (قيمة مؤقتة؛ راجع نطاق الإطلاق)، وترويسة المصادقة `Authorization: Bearer sk-...`.

## استخدام Codex CLI

أضف هذا إلى `~/.codex/config.toml` (أنشئ الملف إذا لم يكن موجودًا):

```toml
model = "gpt-6-astra"
model_provider = "vantyr"

[model_providers.vantyr]
name = "Vantyr"
base_url = "https://vantyr.xyz/v1"
wire_api = "responses"
env_key = "VANTYR_API_KEY"
```

ثم صدّر مفتاحك وشغّل:

```bash
export VANTYR_API_KEY="sk-..."
codex
```

**الطُّرز الموصى بها:** `gpt-6-astra` (الرائد)، `gpt-5-6-luna` (الاقتصادي). تعمل طُّرز Claude في أي أداة متوافقة مع OpenAI.

## استخدام أي عميل متوافق مع OpenAI

```bash
curl https://vantyr.xyz/v1/chat/completions \
  -H "Authorization: Bearer sk-..." \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-5", "messages": [{"role": "user", "content": "Hello!"}]}'
```

لمستخدمي Claude Code وSDK الخاص بـ Anthropic: اضبط `ANTHROPIC_BASE_URL` على `https://vantyr.xyz` و`ANTHROPIC_API_KEY` على مفتاح Vantyr الخاص بك.

## الشهري غير المحدود — 180 دولارًا

دفعة واحدة، 30 يومًا، استخدام **غير محدود** لـ Claude + Codex. لا فوترة بحسب وحدات Token، ولا فواتير مفاجئة.

- سعر ثابت قدره 180 دولارًا شهريًا، مع إمكانية الإلغاء في أي وقت (ينتهي الوصول ببساطة؛ أعد الشراء للتجديد)
- جميع الطُّرز مشمولة، وبواجهة API نفسها
- تسري حدود الاستخدام العادل على الطلبات

[اشترك من صفحة التسعير](/pricing)

## الأسئلة

- **خطأ "insufficient quota"؟** محفظتك فارغة — اشحن الرصيد من صفحة [المحفظة](/wallet).
- **خطأ "429 rate limit"؟** بلغت الحد الأقصى للطلبات في الدقيقة. انتظر دقيقة، أو تواصل معنا لرفع حدك.
- سجل الاستخدام: تعرض صفحة [السجلات](/logs) كل طلب مع وحدات Token وتكلفته.
